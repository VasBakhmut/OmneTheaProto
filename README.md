# OmneThea — перша ітерація

Локальний Next.js прототип. Запуск: `npm install`, потім `npm run dev`. Адреса: http://127.0.0.1:3002 .

RU/EN перемикаються в шапці. Три формати відкривають демонстраційне вікно покупки. Реальна оплата не підключена. Ціни 990 / 1490 / 2490 ₽ — попередні. Усі редакційні тексти потребують затвердження. Обкладинка — CSS макет за наданим фото, не оригінал; англійська версія обкладинки також концептуальна. Фото автора надане користувачем. Інтерфейсні рамки на фото приховані компонуванням, вихідне фото не змінено.

Секції: hero; про книгу; практика; фрагмент; пауза; автор; проєкт; формати; отримання; FAQ; фінальний CTA; підвал. Справжніх цитат, відгуків і уривків не вигадано. Мова інтерфейсу не підтверджує мову видання. robots noindex для прототипу.

До запуску: затверджені тексти, обкладинка, портрет, ціни, мови видань, посилання оплати кожного формату, умови доставки й юридичні документи. NestJS поки не потрібен.

OG: app/opengraph-image.tsx (1200x630), Twitter card, SVG favicon та Apple icon 180x180. Перед публікацією встановіть NEXT_PUBLIC_SITE_URL на справжній HTTPS домен і виконайте нову збірку. Без домену прототип використовує http://127.0.0.1:3002; зовнішні месенджери не можуть завантажити локальне прев’ю. Іконка — концептуальний знак-зірка з дизайну сайту, не затверджений логотип.
